# Программа испытаний офлайн-агрегатора оценок с заказчиком

Дата испытаний: 09.11.2026

## 1. Цель испытаний

Проверить вместе с заказчиком, что офлайн-агрегатор оценок решает задачу представителя жюри: принимает от 2 до 5 заполненных файлов Excel, находит в них ошибки, считает итоговый рейтинг, собирает комментарии экспертов в «Советы на будущее» и выгружает итоговый отчёт в Excel.

Кроме работы приложения нужно уточнить у заказчика несколько вопросов по критериям и правилам расчёта (раздел 5).

## 3. Подготовка

Приложение запускается на одном компьютере и не требует интернета. Подробная инструкция есть в разделе «Офлайн-агрегатор оценок (этап 1)» файла README.md.

1. Установить Python 3.12 и запустить приложение из папки `backend`:

   ```bash
   python -m venv .venv
   source .venv/bin/activate        # в Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   uvicorn main:app
   ```

   Вместо этого можно запустить приложение через Docker командой `docker compose up --build` из корня репозитория.
2. Открыть в браузере http://localhost:8000.
3. Подготовить файлы из папки `examples/`:
   - `Эксперт_1_Соколова.xlsx`, `Эксперт_2_Морозов.xlsx`, `Эксперт_3_Лебедева.xlsx`: три корректных файла экспертов;
   - `С_ошибками.xlsx`: файл с намеренно допущенными ошибками.
4. Взять шаблон `docs/Шаблон_оценки_жюри.xlsx` (его же отдаёт кнопка «Скачать шаблон для жюри») и, если заказчик согласен, заполнить его своими данными для сценария 10.
5. Для сценария 8 заранее сохранить копии одного из файлов, в которых ФИО одного участника написано по-разному («Ёлкин Иван» и «елкин иван»).
6. Для сценария 7 подготовить файл старого формата .xls (или документ Word, переименованный в .xlsx).

## 5. Вопросы к заказчику

1. Максимумы баллов по четырём критериям отличаются на бумажном бланке и в таблице критериев: «Логичность и полнота» (3 или 4), «Аргументация выводов» (5 или 4), «Ответы на вопросы» (5 или 4), «Качество презентации» (2 или 3). В приложении сейчас значения из таблицы критериев. Какие значения верны?
2. Допустимы ли дробные баллы? Сейчас шаблон принимает только целые, но при загрузке дробные значения («2,5») приложение не отклоняет.
3. Всегда ли один расчёт относится к одной секции? Если файлы относятся к разным секциям, приложение только показывает предупреждение.
4. Кто выставляет балл по критерию «Отзыв партнёра»: эксперт или организатор?
5. Нужно ли учитывать подпись эксперта на бланке?
