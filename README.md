# Автоматизация бизнес-процессов Инженерной школы
**Веб-система для сопровождения проектной деятельности школьников.**

Система предназначена для преподавателей и администраторов и должна объединить работу со списками школьников, школами и классами, проектными командами, занятиями, посещаемостью, историей работы над проектами и отчётностью.

---

> **Важно:** Это репозиторий **модуля электронного оценивания проектов**. 
> Он разрабатывается как самостоятельная подсистема и в дальнейшем будет интегрирован в основную систему Инженерной школы.

## Модуль электронного оценивания проектов

Данный репозиторий содержит разработку **подсистемы электронного оценивания проектов**. 

Сейчас жюри оценивает проекты на бумажных бланках. Из-за этого данные теряются, итоги считаются вручную, а вопросы, которые не успели задать устно, пропадают. Наш модуль решает эти проблемы: баллы сразу попадают в базу, итог считается автоматически, а вопросы, заданные экспертами, сохраняются, и участники могут ответить на них письменно после выступления.

**Цель:** автоматизация оценивания проектов экспертной комиссией за счёт замены бумажных бланков системой, которая обеспечивает заполнение бланков онлайн, письменные ответы участников на вопросы жюри и хранение всех данных в единой базе.

> **Статус:** На первом этапе (MVP к 28.12.2026) система работает самостоятельно и локально. После защиты модуль будет интегрирован в основную систему Инженерной школы как подсистема.

## Роли пользователей

В системе предусмотрено три роли. У каждого пользователя свой аккаунт; роль определяет, что он видит после входа (самостоятельной регистрации нет, аккаунты заводит администратор).

| Роль | Что делает | Ограничения |
| :--- | :--- | :--- |
| **Администратор** | Создаёт конкурсы, добавляет жюри, закрепляет за каждым членом жюри его проекты, настраивает критерии, видит и выгружает все данные | Единственная роль с доступом к управлению конкурсами и пользователями |
| **Жюри (Эксперт)** | Видит свои конкурсы и закреплённые проекты, ставит баллы по критериям, задаёт вопросы, видит ответы участников и начисляет за них дополнительные баллы | Оценивает только закреплённые за ним проекты; чужие оценки не видит |
| **Участник** | Видит свои проекты и баллы жюри, отвечает на вопросы жюри и получает за это дополнительные баллы | Может быть в нескольких проектах, но в одном конкурсе — только в одном проекте |

## Ключевые особенности и бизнес-логика

*   **Онлайн-бланки:** Бланк можно сохранить как черновик и отправить окончательно. После отправки правка возможна только с разрешения администратора.
*   **Гибкие критерии:** Критерии и шкалы (максимумы баллов) хранятся в базе данных как настройки конкурса, а не в коде. Изменение регламента меняет настройки, а не программу.
*   **Вопросы и ответы:** Жюри может задавать вопросы по критериям, где балл ниже максимума. Если вопрос не успели задать устно, он открывается участнику для письменного ответа (пока не истёк срок приёма ответов).
*   **Автоматический подсчёт:** Итоговый балл проекта — среднее арифметическое итоговых баллов всех членов жюри, закреплённых за проектом (по отправленным бланкам). Дополнительные баллы за ответы начисляются участнику лично и не входят в общий итог проекта.
*   **Безопасность данных:** Все бланки, вопросы и ответы хранятся в общей базе. Пользователь видит только данные своей роли. Пароли хранятся в зашифрованном виде (хеш).

## Офлайн-агрегатор оценок (этап 1)

Приложение для представителя жюри. Эксперты заполняют Excel-шаблон, организатор секции загружает от 2 до 5 файлов, а приложение проверяет баллы, считает итоговый рейтинг и собирает комментарии в «Советы на будущее». Работает локально, без интернета и без базы данных; загруженные файлы нигде не сохраняются.

### Как запустить

Нужен Python 3.12.

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # в Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Страница откроется по адресу http://localhost:8000.

Через Docker (из корня репозитория):

```bash
docker compose up --build
```

Тесты запускаются из папки `backend`:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

### Как пользоваться

1. Скачать шаблон для жюри кнопкой «Скачать шаблон для жюри» (готовый файл лежит в [docs/Шаблон_оценки_жюри.xlsx](docs/Шаблон_оценки_жюри.xlsx)). Если список участников известен заранее, можно скачать шаблон с уже вписанными ФИО.
2. Раздать шаблон экспертам. В нём 12 критериев, максимум 45 баллов, а Excel не даст ввести балл выше максимума.
3. Собрать от 2 до 5 заполненных файлов.
4. Загрузить файлы на странице и нажать «Рассчитать рейтинг». Если в файлах есть ошибки, приложение покажет их все сразу, рейтинг в этом случае не считается.
5. Посмотреть рейтинг и советы на будущее и скачать итоговый отчёт в формате .xlsx: рейтинг, советы и исходные оценки экспертов.

Для пробного запуска можно взять файлы из папки [examples](examples): три корректных файла экспертов и файл с ошибками.

### Структура backend

| Файл | Что делает |
| :--- | :--- |
| `main.py` | FastAPI-приложение и маршруты |
| `criteria.py` | 12 критериев с максимумами баллов, общая сумма 45 |
| `jury_template.py` | сборка шаблона Excel для жюри |
| `excel_reader.py` | чтение файла эксперта и проверка баллов |
| `rating.py` | расчёт рейтинга, мест, предупреждений и советов |
| `report.py` | итоговый отчёт в Excel |
| `templates/`, `static/` | страница приложения (HTML, CSS, JavaScript) |
| `tests/` | тесты |

Документация API доступна по адресу http://localhost:8000/docs (для этой страницы нужен интернет).
